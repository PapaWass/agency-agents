# Waterfall Phase Index

Maps every agent to its primary activation phase in a sequential project lifecycle. Agents appear in the earliest phase where they contribute — many remain active in later phases.

> Cross-reference with [strategy/nexus-strategy.md](strategy/nexus-strategy.md) for full orchestration playbooks.

---

Research, domain expertise, and user/market understanding. Nothing gets built until this phase produces actionable insights.

## Dependency Flow

```
Phase 0 ──→ Phase 1 ──→ Phase 2 ──→ Phase 3 ──→ Phase 4 ──→ Phase 5 ──→ Phase 6
Discovery    Strategy    Design     Build       Harden      Launch      Operate
                                      ↑            │
                                      └── fix ──────┘
                                    (Dev↔QA loop)
```

Cross-cutting agents (project-management/, orchestration/) are active across all phases.
Regional consultants activate on-demand when entering specific markets.
